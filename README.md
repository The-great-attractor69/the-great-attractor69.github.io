# atta ullah upgraded portfolio

static github pages portfolio using html, css, javascript, and tailwind css via cdn.

included:
- interactive html5 canvas skill network
- hover proximity, glowing connections, clickable skill filtering
- live system load simulator with green/amber/red states
- live terminal log output
- command center modal with `~` shortcut
- commands: help, skills, projects, about, contact, resume, load, clear
- problem / solution / impact project tabs
- animated metric counters
- exploration progress tracker and completion confetti
- glassmorphism dark interface
- responsive layout and reduced-motion support

before publishing:
1. add your real linkedin and github urls in index.html.
2. place your actual resume as `resume.pdf` in the repository root.
3. replace generic project copy with your final case-study text.
4. use only anonymized screenshots and non-confidential work samples.
5. enable github pages from the main branch.

note: tailwind is loaded through the cdn. the custom visual system remains in style.css so there is no build process.
